# 🎲 Number Guessing Game (Python)

An amusing and simple **Number Guessing Game** made from Python.  
The players will establish the lower and upper limits and the program will pick out a number in that particular range randomly. You have **7 attempts** to go for the right number and get help with hints during this process!

---

## 🚀 Characteristics
- User-defined **lower and upper bounds** 🎯
- Random number generation through Python’s `random` module
- **7 attempts** to guess the number
- Interactive hints:
  - "The number is too high! Try a lower one."
  - "The number is too low! Try a higher one."
- Counts the number of attempts and shows success/failure messages
